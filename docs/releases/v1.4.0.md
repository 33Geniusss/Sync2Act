# Sync2Act v1.4.0

Windows x64 portable application. Extract the complete ZIP and run
`Sync2Act/Sync2Act.exe`, keeping `_internal` beside it. Python is bundled.

## Changes

- Added paired clean/corrupted-test evaluation with the same checkpoint and frozen
  training normalization. Test action labels, timestamps and episode order remain
  unchanged; source datasets are not modified.
- Added image, state and mixed observation faults with causal delay, missing
  segments, camera selection, reproducible seeds, and Oracle/unknown quality modes.
- Added background evaluation, cancellation, checkpoint dataset/split checks,
  per-episode and affected/unaffected metrics, and paired HTML/JSON export.
- Added a resumable historical-checkpoint study and an integrated bilingual
  v1_4_0 report connecting training quality, test robustness and temporal ensembling.
  The recorded study contains 4,158 evaluations with 270 clean-baseline audits.
- Extended packaged-application diagnostics to exercise paired test corruption and
  HTML/JSON export on CPU and CUDA when available.

## Compatibility and evidence limits

- CPU execution is available; the Windows package includes the CUDA 13.0 PyTorch
  runtime and uses a compatible NVIDIA GPU/driver when available.
- Schema-3 exact resume and best-validation checkpoint selection are retained.
  Historical evaluation checkpoints require their original dataset and recorded
  test partition; sibling `run.json` records can supply older study metadata.
- Oracle quality is known synthetic-fault metadata. Unknown mode hides that
  metadata without repairing observations. Automatic quality detection is not
  implemented. Offline prediction errors do not establish closed-loop success.
- The historical 270 models were not retrained. No dataset, trained model or
  credential is bundled with the application.

event-loop tests; Ruff and the four registered documentation language pairs passed.
Source-mode diagnostics also passed native Parquet/video, CPU/CUDA exact resume,
